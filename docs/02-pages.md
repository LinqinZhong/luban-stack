# 页面怎么用

页面是用户能「打开」的一屏。每个页面有自己的界面、数据和方法。

## 你要配置什么

1. **标识与标题**：在项目里叫什么、导航上显示什么。  
2. **入口**：是否作为应用启动页（在项目配置里指定）。  
3. **壳层**：状态栏颜色、是否覆盖内容、是否显示原生导航等（按目标端场景需要）。  
4. **路由入参**：打开本页时允许携带哪些参数、类型与默认值；预览时可给调试用入参。  
5. **界面 / 数据 / 逻辑**：分别编辑布局、数据池、方法与生命周期。

## 打开与跳转

- 用页面标识跳转，并可附带参数对象。  
- 目标页在数据绑定和逻辑里通过「查询参数」命名空间读取入参。  
- 需要返回时调用返回能力即可。

## 使用建议

- 列表进详情：列表页跳转时带上主键；详情页用入参去拉数据或绑接口。  
- 壳层样式若依赖滚动、主题，可用数据池计算字段驱动，而不是写死。  
- 页面保持「薄」：复杂列表、选择器、分页等下沉为组件。
