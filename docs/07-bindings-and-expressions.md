# 绑定与表达式怎么用

界面属性可以写死，也可以写成「从当前作用域算出来的值」。

## 能读到什么

| 来源 | 典型用途 |
|------|----------|
| 当前数据池字段 | 展示业务状态 |
| 组件属性 | 子组件读父级传入的值 |
| 路由查询参数 | 详情页读打开时带的 id 等 |
| 主题色 | 统一品牌色 |
| 列表当前项 / 下标 | 重复渲染时的每一项 |

表达式按脚本求值：可做简单运算、三元、取字段路径等。用来**取值**，不要在绑定里做跳转、写库等副作用。

## 条件与样式

- **条件显示**：一组规则（字段比较、是否为空等），决定显示或隐藏/卸载。  
- **动态样式**：规则命中时覆盖背景、文字色、尺寸等，适合选中态、激活态。

规则可组合：多条件同组一般为「且」，多组一般为「或」（以实现为准，编辑器里按场景配置即可）。

## 使用建议

1. 文案、显隐、选中态优先绑定，少改布局硬编码。  
2. 复杂逻辑放到方法；绑定只保留可读表达式。  
3. 列表里用「当前项」展示，点选时把意图通过事件抛给父级。  
4. 颜色跟主题走，便于整站换肤。
