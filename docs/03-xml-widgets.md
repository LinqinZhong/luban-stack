# 界面控件怎么用

界面是一棵控件树：叶子负责展示与输入，容器负责排布与结构。

## 控件角色

| 角色 | 典型用途 |
|------|----------|
| 文本 / 按钮 / 输入 | 展示文案、触发操作、收集输入 |
| 图片 / 图标 | 媒体与符号（图标来自项目图标库） |
| 线性布局 | 按横向或纵向依次排子节点 |
| 相对布局 | 相对父级贴边、居中定位 |
| 轮播 | 多个子节点当作多页切换 |
| 多窗口 | 同一区域按当前键只显示其中一个子窗口 |
| 弹层 | 全屏遮罩层，内容在其内相对定位 |
| 组件引用 | 嵌入已定义的业务组件，并填插槽 |
| 插槽 | 仅在组件内部：声明「父级可往这里塞内容」 |
| 片段根 | 组件需要多个顶层节点时使用 |

## 怎么选

1. **默认用线性布局**做主结构；需要叠在底部栏、角标等再用相对布局。  
2. **Tab / 多页同屏切换**用多窗口，用一个变量表示当前页。  
3. **可复用块**不要复制粘贴大段树，做成组件再引用。  
4. **弹窗、规格选择**等用弹层或组件 + 引用，由数据池「引用」调用显示/隐藏或暴露方法。

## 嵌套直觉

- 只有容器类节点能挂子控件。  
- 组件引用的子节点按「插槽名」归入组件内部对应插槽。  
- 轮播的直接子节点通常表示每一页内容。
