# 数据池怎么用

数据池是当前页面或组件的本地状态表。界面读它，方法改它。

## 字段从哪来

| 来源 | 含义 |
|------|------|
| 普通字段 | 自带初始值；逻辑里赋值更新 |
| 计算字段 | 由其它字段推导，只读结果（适合透明度、主题色合成） |
| 接口字段 | 绑定某个后端 API，按入参自动请求，结果写入本字段 |
| 资源字段 | 关联对象存储等外部资源 |
| 引用字段 | 指向界面树上某个节点，用来调用其暴露方法或弹层显隐 |

字段有类型（文本、数字、布尔、对象、数组、颜色、时间等），复杂结构可挂类型库。

## 怎么用

1. **界面**：用绑定表达式读字段或其子路径。  
2. **逻辑**：用更新能力改普通字段；组件里若属性可回写，用「更新属性」把结果推回父级。  
3. **进页拉数**：用接口字段 + 入参绑定（常绑路由查询参数）；或生命周期里调方法。  
4. **命令子组件**：建引用字段，在方法里调用其暴露方法。

## 使用建议

- 页面数据池放「这一页关心的状态」；列表内部翻页状态放组件数据池。  
- 能计算出来的不要再存一份，避免不同步。  
- 接口字段适合声明式拉数；复杂编排（多步、分支）放到方法或后端业务流。
