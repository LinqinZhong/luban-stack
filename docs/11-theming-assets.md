# 主题与资源怎么用

## 颜色

在项目主题里定义命名色，界面用主题色绑定，而不是到处写死色值。  
换品牌色时改一处即可影响全局。

## 图标

图标集中在项目图标库；界面用图标控件按标识引用。  
不要在布局里嵌原始矢量大段内容。

## 存储与数据库连接

对象存储、数据库连接属于项目级资源，供服务与资源型数据使用。  
页面作者通常通过接口间接使用数据，而不是在界面里配连接串。

## 构建与运行环境

- 用构建方案决定导出哪些页面与服务。  
- 用项目配置里的接口基址、小程序标识、画布场景等对齐目标运行环境。  

本地调试与正式环境应主要通过基址/构建方案切换，而不是改业务绑定里的主机名。
