# 属性怎么挂到控件上

每个控件有一批属性：尺寸、间距、外观、结构行为、交互。值可以是固定量，也可以绑定表达式。

## 四类属性

### 1. 布局与盒模型

宽高（铺满父级 / 包内容 / 固定像素）、内外边距、背景、边框、圆角、层级、间距、对齐、溢出（是否可滚动）等。  
先定宽高与方向，再微调间距与对齐。

### 2. 相对定位（相对布局的子节点）

贴父边、水平/垂直居中等开关。用于底栏、浮动按钮、角标。

### 3. 结构行为

| 能力 | 何时用 |
|------|--------|
| 列表重复 | 同一子树按数组逐项渲染；项内有「当前项 / 下标」 |
| 条件显示 | 按规则隐藏或卸载（隐藏保留树，卸载则销毁） |
| 动态样式 | 按规则覆盖部分样式（如选中高亮） |
| 插槽名 | 作为组件子节点时，标明填入哪个插槽 |

### 4. 交互

点击、长按；可滚动容器还可配滚动、触底/触顶、触摸。  
属性值不是「写死一段脚本文件名」，而是一条条「事件绑定」（调方法、改数据、自定义语句等），可串联多条。

## 使用建议

- 能绑定就绑定：文案、显隐、选中态尽量跟数据池走，少写死。  
- 滚动相关事件只在「允许滚动」的容器上配置。  
- 颜色优先用主题色或数据池颜色字段，便于换肤。
